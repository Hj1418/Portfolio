Systems I've Architected

Enterprise Hybrid Encryption & Secure File Exchange

Problem: Organizations needed to securely store and exchange sensitive documents while ensuring confidentiality, efficient encryption for large files, and secure key management without exposing encryption keys.
Solution: Designed and implemented a hybrid encryption framework combining AES-256 for high-performance file encryption and RSA for secure encryption and exchange of AES keys.
My Contribution: Designed the hybrid encryption workflow, implemented AES-256 file processing, integrated RSA key pair management via Java Cryptography Architecture (JCA), and built secure REST endpoints.
Challenges: Managing the performance overhead of RSA decryption during batch file retrievals and ensuring thread-safe key generation.
Key Learnings: Using AES for bulk data and RSA exclusively for key protection achieves optimal cryptographic speed without compromising transport layer security.
Future Improvements: Add support for hardware security module (HSM) integrations to offload and secure private key stores.
Java Spring Boot AES-256 RSA JCA REST APIs PostgreSQL

Multi-Tenant Organization Management Platform

Problem: Organizations needed to securely manage users, roles, and files with strict data isolation, avoiding data cross-contamination and auth latency.
Solution: Architected a multi-tenant SaaS backend utilizing database-level tenant isolation, JWT authentication, and Keycloak integration.
My Contribution: Led backend architecture development, designed PostgreSQL schemas, integrated Keycloak OAuth2 with Spring Security.
Challenges: Resolving dynamic datasource routing context maps per request under high-frequency concurrency.
Key Learnings: Dynamic Hibernate connection pooling, context holding filters, and containerized OAuth flow security configurations.
Future Improvements: Implement microservice split for file upload streaming with localized edge caching.
Java Spring Boot PostgreSQL Keycloak OAuth2 RBAC

AI-Powered Document Intelligence

Problem: Clients needed summarization and analytics on highly sensitive files without sending data off-premises to external public LLM APIs.
Solution: Built an on-premises document parsing and semantic intelligence pipeline using locally hosted LLMs.
My Contribution: Built the document ingestion parser, integrated semantic chunking algorithms, and configured Ollama service hooks.
Challenges: Handling context window limits on local models and parsing structured PDF data accurately.
Key Learnings: Prompt engineering constraints, context limits, and hardware optimization for local inference.

Ollama Spring Boot Semantic Chunking Prompt Design Privacy-First AI

Solution: Created a highly resilient Java-based telemetry receiver fetching data via MQTT protocol from physical ESP8266 boards.
My Contribution: Configured MQTT channels, established database schema persistencies, and structured socket handling.
